# 08 - Training LLMs from Scratch

This module puts the earlier concepts into practice by building and training language models end to end. It opens with a primer that follows the whole of Andrej Karpathy's [*Let's build GPT*](https://www.youtube.com/watch?v=kCc8FmEb1nY) lecture alongside an interactive visualizer, from a bigram lookup table to a full Transformer, with thanks to him for the lecture and its MIT-licensed code. Each chapter after that is a complete build of one model version, taking it from raw text to a trained model that generates text. It starts with a GPT-style decoder, and later chapters add newer architectures and larger training recipes on top of the same pipeline.

```objectives
scope: module
time: 3-4 hours (growing as builds are added)
outcomes:
  - Trace a minimal language model (a bigram lookup table) from (B, T) token ids to logits, loss and sampled text
  - Run every step of a from-scratch pretraining pipeline in the right order, from data cleaning to sampling
  - Split train and validation data without leakage, and build (x, y) context blocks and batches from a token stream
  - Implement and size a GPT-style decoder, predicting its parameter count and training compute before running it
  - Train it with a correct loop (AdamW, LR schedule, gradient accumulation, clipping, bf16) and diagnose it from the loss curves
prerequisites:
  - "[Foundation Models](../03-Foundation-Models/INDEX.mdx) - tokenization, the transformer and attention"
  - "[PyTorch Fundamentals](../06-PyTorch/INDEX.mdx) - the training loop and the GPT From Scratch lab"
  - "[Pretraining at Scale](../07-Pretraining/INDEX.mdx) - objectives, data curation and scaling laws"
```

## Code Lab

The runnable companion for this module is the [GPT From Scratch lab](../06-PyTorch/CodeLabs/02-GPT-From-Scratch.mdx) in PyTorch Fundamentals. It is a modernized version of the model built in chapter 2, with RMSNorm, RoPE, grouped-query attention and SwiGLU, trained on Tiny Shakespeare, and a smoke test that runs on a laptop CPU.
