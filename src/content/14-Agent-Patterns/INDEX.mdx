# 14 - Agent Patterns & Multi-Agent

Once a single agent works, the design question becomes structure: one agent or several, who plans and who executes, how work is routed, checked and combined. This module catalogues the architectural patterns (how agents are arranged), the design patterns (how each agent behaves), and what changes when multiple agents coordinate.

```objectives
scope: module
time: 6-8 hours
outcomes:
  - Name the main architectural patterns (sequential, parallel, hierarchical, orchestrator-subagent, pipeline, debate, reflexion) and pick one for a given problem
  - Apply the core design patterns - tool use, reflection, planning, routing, coordination - inside any architecture
  - Explain when multiple agents beat one agent with more tools, and when they only add cost and failure modes
  - Diagnose common multi-agent failures - lost context between agents, runaway loops, conflicting outputs
  - Implement a pattern in at least one framework using the code labs
prerequisites:
  - "[Agent Foundations](../12-Agent-Foundations/INDEX.mdx) - the agent loop, tools, memory and planning"
```
