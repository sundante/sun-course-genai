# 12 - Agent Foundations

An AI agent is an LLM that runs in a loop: it reads its context, decides on an action (usually a tool call), observes the result, and repeats until the goal is met. This module builds that idea from first principles - the loop, tools, memory and planning - before later modules add protocols (13), multi-agent patterns (14), frameworks (15) and production concerns (16).

```objectives
scope: module
time: 8-10 hours
outcomes:
  - Explain what separates an agent from a chatbot or a fixed workflow, and place a system on the autonomy spectrum
  - Trace the agent loop at the API level - what the model sees on each turn and how tool results re-enter the context
  - Design tool schemas and error handling that a model can use reliably
  - Choose between working, episodic, semantic and procedural memory for a given task, and manage context over long runs
  - Compare planning strategies (ReAct, plan-and-execute, reflection) and know when a reasoning model changes the choice
  - Build a first evaluation set for a single agent
prerequisites:
  - "[LLM Foundations](../01-LLM-Foundations/INDEX.mdx) - tokens, context windows, sampling"
  - "[Prompt & Context Engineering](../10-Prompt-Engineering/INDEX.mdx) - system prompts and structured output"
```
