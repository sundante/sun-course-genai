# 15 - Agent Frameworks

Frameworks package the agent loop, tool calling, state and orchestration so you don't rebuild them for every project. They also hide those mechanics, which is why this module comes after you have built the loop by hand. Here you compare the major frameworks and build the same agents in each.

```objectives
scope: module
time: 10-14 hours (including labs)
outcomes:
  - Explain what an agent framework adds on top of a raw model API loop, and what it hides
  - Compare frameworks by their core abstraction - graph, conversation, crew of roles, or event-driven runner - and pick one for a project
  - Build single agents of increasing complexity in LangChain, LangGraph, CrewAI and Google ADK
  - Build an end-to-end multi-agent system (research, document processing, planning or code review) in one framework
prerequisites:
  - "[Agent Foundations](../12-Agent-Foundations/INDEX.mdx) - the agent loop and tool use"
  - "[Agent Patterns & Multi-Agent](../14-Agent-Patterns/INDEX.mdx) - the patterns the labs implement"
  - Python 3.10+ and an API key for at least one model provider
```
