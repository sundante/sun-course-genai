# 08 - Post-Training & Fine-Tuning

A pretrained base model continues text; it does not follow instructions, refuse harmful requests, or reason step by step on demand. Post-training adds those behaviours: supervised fine-tuning on demonstrations, preference optimization, and reinforcement learning - including the RL-with-verifiable-rewards recipe behind today's reasoning models. The second half of the module does it by hand with the Hugging Face stack: LoRA and QLoRA configuration, instruction data with masked losses, reading loss curves, and benchmarking a fine-tune against its base - then the full SFT, DPO and GRPO sequence with TRL.

```objectives
scope: module
time: 14-18 hours (notes + labs, plus GPU time)
outcomes:
  - Explain the post-training pipeline from SFT to preference tuning to RL, and what each stage changes in the model
  - Compare RLHF with PPO, DPO-family methods and GRPO by what they need (reward model, critic, online samples) and what they cost
  - Describe how RL with verifiable rewards produces long chain-of-thought reasoning
  - Configure and run LoRA and QLoRA fine-tunes with masked instruction data, and diagnose runs from loss curves
  - Benchmark a fine-tune against base and prompted baselines on quality, latency, VRAM and cost, and run SFT, DPO and GRPO with TRL
prerequisites:
  - "[Foundation Models](../03-Foundation-Models/INDEX.mdx) and [PyTorch Fundamentals](../06-PyTorch/INDEX.mdx)"
  - "[Pretraining at Scale](../07-Pretraining/INDEX.mdx) - especially the training memory math"
```
