# 16 - Production Agents

A demo agent needs to work once; a production agent needs to work reliably, safely and affordably on inputs nobody anticipated. This module covers the engineering around the agent: system design, reliability, human oversight, cost, evaluation and observability, with worked system-design case studies.

```objectives
scope: module
time: 8-10 hours
outcomes:
  - Design an agentic system end to end - components, state, failure handling, human-in-the-loop gates and cost controls
  - Build trajectory-level evaluations and choose between code-based, model-based and human graders
  - Instrument an agent for observability and debug a failed run from its trace
  - Present a production agent design in a system-design interview format
prerequisites:
  - "[Agent Foundations](../12-Agent-Foundations/INDEX.mdx)"
  - "[Agent Patterns & Multi-Agent](../14-Agent-Patterns/INDEX.mdx)"
```
