# 09 - Cloud Platforms

## What You Will Learn

- AWS Bedrock: Converse API for unified model access, Knowledge Bases for managed RAG, Guardrails, AgentCore, and cost/customization levers (batch, prompt caching, provisioned throughput, Custom Model Import)
- Databricks and Spark: the medallion architecture, Delta Lake, Unity Catalog, MLflow, and DBU cost levers
- Microsoft Foundry (formerly Azure AI Foundry): model catalog, Foundry Agent Service, evaluations, Microsoft Fabric vs BigQuery, Azure SQL/Cosmos DB
- Google Cloud's Gemini Enterprise Agent Platform (formerly Vertex AI): Model Garden, ADK, Agent Runtime, Memory Bank, governance
- How to translate experience on one cloud into credible vocabulary on the others
- A reusable Google Cloud ↔ AWS ↔ Azure comparison table, plus where GPU clouds and inference providers fit
