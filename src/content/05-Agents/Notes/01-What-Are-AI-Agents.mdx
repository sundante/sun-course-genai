# What Are AI Agents

## The One-Line Definition

An AI Agent is a software system that **perceives its environment, reasons about a goal, plans a sequence of actions, and executes those actions autonomously** — repeating this loop until the goal is achieved or it decides to stop.

Unlike a chatbot that responds to a single prompt, an agent can take multiple steps, use external tools, remember previous actions, and adapt when things go wrong.

---

## Chatbot vs Automation vs AI Agent

| | Chatbot | RPA / Automation Script | AI Agent |
|---|---|---|---|
| **Input** | Natural language prompt | Predefined trigger / schedule | Natural language goal |
| **Reasoning** | Single LLM call | Hardcoded logic | Multi-step LLM reasoning |
| **Actions** | Text response only | Fixed sequence of steps | Dynamic tool selection |
| **Adaptability** | None — reruns from scratch | None — breaks on unexpected input | High — replans on failure |
| **Memory** | Context window only | None (stateless) or DB | Short-term + optional long-term |
| **Example** | "Summarize this email" | "Every day at 9am, send report" | "Research competitors and draft a report, then email it to the team" |

## The Four Pillars of an AI Agent

### 1. Perceive
The agent takes in context — a user request, tool output, memory, environment state. This is the raw input that feeds the reasoning engine.

### 2. Reason
The LLM at the agent's core interprets the input, decides what to do next, and generates a plan or action. This is where chain-of-thought, ReAct, and other reasoning strategies apply.

### 3. Plan
For multi-step goals, the agent sequences sub-tasks. Some agents plan upfront (Plan-and-Execute), others plan one step at a time (ReAct), and some use a separate planner LLM.

### 4. Act
The agent executes an action — calling a tool, writing to a file, sending an API request, spawning a sub-agent. The result feeds back into the next Perceive step.

This **Perceive → Reason → Plan → Act** loop runs until the task is complete.

---

## Why an LLM + a Database Is Not an Agent

A common misconception is that connecting an LLM to a data source creates an agent. It doesn't. The LLM can now retrieve facts — but it still can't *act* on the world.

A functioning agent system requires four coordinated components:

| Component | Role |
|---|---|
| **AI Model** | Reasoning engine — interprets context and decides what to do |
| **Data Layer** | Real-time access to live systems (databases, APIs, documents) |
| **Code Execution** | Runs computations, calls APIs, performs actions |
| **Specialized Models** | Handles domain-specific sub-tasks (vision, classification, scoring) |

The power of an agent comes from **orchestrating these four components together** — not from any single component in isolation. Swapping in a smarter model without the surrounding system produces a smarter chatbot, not an agent.

## The Four Characteristics of an Agent

Beyond the perceive-reason-plan-act loop, agents are defined by four behavioral characteristics:

### Reflective
An agent monitors its own outputs and adjusts its approach when something isn't working. For example, if a classification agent's accuracy starts dropping on a new data distribution, it can detect this signal and revise its strategy — without human intervention.

### Interactive
An agent communicates across multiple parties — users, other agents, and external systems. It adapts its communication style to context (technical when querying an API, plain language when responding to a user).

### Reactive and Proactive
An agent doesn't just respond to what has happened — it also anticipates what's needed. A reactive agent responds to a user's request; a proactive agent notices a missing document mid-task and requests it *before* being asked, rather than failing later.

### Autonomous
An agent operates across a sequence of steps without requiring human confirmation at each one. Once given a goal, it makes the intermediate decisions itself.

## The Perception Component

The Perceive step in the agent loop is more than just reading a user message. A full perception layer:

- Receives inputs across multiple modalities: **text, audio, images, structured data**
- Processes and normalizes them into a unified representation the LLM can reason over
- Updates the agent's current state before each reasoning step

**Perception cycle:**
```
Sensors (inputs) → Processing (normalization, extraction) → State Update (agent context refreshed)
```

**Example:** A health monitoring agent doesn't just read a user's text question. It simultaneously ingests meal photos, dietary preference data, and health metrics — processes all of them — then updates its understanding of the user's current state before deciding what to recommend.

## The Autonomy Spectrum

Not all AI systems are fully autonomous agents. Think of it as a dial:

```
Low Autonomy                                    High Autonomy
     │                                               │
     ▼                                               ▼
 Copilot          Assistant          Autonomous Agent
(human drives)  (human confirms)    (agent decides)

 GitHub Copilot   ChatGPT plugins    AutoGPT / CrewAI
 Code suggestions  Single tool call   Full research loop
```

| Level | Human Role | Best For |
|---|---|---|
| **Copilot** | Reviews and accepts every suggestion | Code completion, writing assistance |
| **Assistant** | Approves key decisions, reviews output | Customer support, data lookup |
| **Autonomous** | Sets goal and reviews final result | Complex research, multi-step pipelines |

Most production systems sit at **Assistant** level — agents that can do significant work but check in at decision points.

## What Makes an Agent "Intelligent"

The intelligence comes from combining these capabilities:

1. **Tool use** — the ability to call external functions (search, calculate, query a DB) rather than hallucinating answers
2. **Multi-step reasoning** — breaking a complex goal into smaller steps and executing them in sequence
3. **Self-correction** — detecting when a tool call failed or an answer is wrong and trying a different approach
4. **Memory** — not forgetting what was done 5 steps ago in a long task
5. **Goal orientation** — staying focused on the original objective across many intermediate steps

---

## Study Notes

- An agent is defined by its **autonomy** — it decides what to do next, not just responds
- The core loop is always **Perceive → Reason → Plan → Act → repeat**
- The LLM is the **brain**, tools are the **hands**, memory is the **notepad**
- Autonomy exists on a **spectrum** — most production agents are semi-autonomous (human confirms key decisions)
- The difference between an agent and a chain: a **chain** has a fixed sequence, an **agent** decides the sequence dynamically
